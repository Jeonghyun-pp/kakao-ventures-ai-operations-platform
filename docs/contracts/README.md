**schema-on-read 시스템에서 가장 안 본 것이 가장 결정권이 크다.**

## 재생성

`notion/` 은 `scripts` 가 아니라 스크래치의 `fetch.py`/`analyze.py`/`contract.py` 로 만들었다(읽기 전용).

## 규율

- 이 문서들은 **관찰 기록이자 계약**이다. 코드를 고칠 때 여기 어긋나면 **코드가 틀린 것**이다.
- 어긋난 것을 발견하면 계약을 고치지 말고 **먼저 어느 쪽이 옳은지 실측**하라.
- "대체로"·"대부분" 금지. **읽은 수 / 전체 수**로 말한다.
