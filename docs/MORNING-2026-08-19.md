# 1. 노션 자동화 끄기 ⏱ 5분

## 왜

지금 링크드인 DB 의 `DB로 업데이트` 체크박스를 켜면 **두 곳에 행이 생깁니다.**

```
체크 ✅ ──┬─→ ⭐ Pick        (동결했습니다. 이제 안 씁니다)
          └─→ 극초기 DB      🔴 사람 이름이 `법인(서비스)` 칸에 들어갑니다
```

`법인(서비스)` 는 **회사명 칸**입니다. 그런데 자동화가 링크드인의 `서비스명`(=사람 이름)을
그대로 복사합니다. 실측으로 **24건**이 그렇게 들어갔습니다 — `Example Person B`·`Example Person A`·
`Example Person D`·`Example Person C`·`Example Person E` 등.

**이걸 안 끄면 제가 만든 승격 코드를 켤 수 없습니다.** 둘 다 켜지면 이중 생성입니다.

## 어디서

노션에서 DB 를 열면 **오른쪽 위에 번개 모양 ⚡** 아이콘이 있습니다. 누르면 그 DB 에 걸린
자동화 목록이 나옵니다.

## 세 곳을 보셔야 합니다

```
① 그물망 링크드인 소싱 DB(링크드인)     ← 확실히 있습니다 (어제 실측)
② 그물망 앱스토어 소싱 DB (앱스토어)     ❓ 체크 14건이 있는데 자동화는 미확인
③ [동결] 그물망 스레드 소싱 DB          ❓ 체크 2건 · 링크드인과 41칸 구조가 같음
```

②③은 있는지 없는지 **저희가 모릅니다.** API 로 자동화를 조회할 수 없어서요.
열어보시고 있으면 끄고, 없으면 없다고 알려주세요.

## 🔴 지우지 말고 꺼주세요

켜기/끄기 토글이 있으면 **끄기만** 해주세요. 지우면 무엇이 있었는지 알 수 없게 됩니다.
토글이 없어서 지워야 한다면 **지우기 전에 화면을 캡처**해주세요.

# 3. 링크드 뷰에 `[뷰]` 표기 ⏱ 5분

## 왜

같은 DB 인데 URL 이 완전히 달라서 **다른 DB 처럼 보입니다.**

```
b14752e3   극초기 스타트업 DB              원본        🟦 KV DB 🟦 아래
fde1fe51   View of 극초기 스타트업 DB      같은 데이터  Service Central 아래
```

어제 정현님도 "다른 거 아니야?" 하고 물으셨죠. 데이터소스가 `EXAMPLE_ID` 하나로 같습니다.

그리고 **우리 코드는 뷰를 404 로 봅니다.** 나중에 뷰 URL 을 설정에 넣으면 코드가 죽습니다.
더 위험한 건 뷰에 필터가 걸려 있을 때입니다 — 화면엔 300행만 보이는데 코드는 1,303행을
읽습니다. "노션에서 봤을 땐 없었는데" 가 나오는 자리입니다.

## 대상

```
Service Central 아래    View of 극초기 스타트업 DB      ← 확인됨
base 부모 페이지 아래    3a40ac54…4d8c · …902d · …1dc4   ← 문서 기록, 미확인
```

## 하는 법

제목 앞에 표시만 붙이시면 됩니다.

```
View of 극초기 스타트업 DB   →   [뷰] 극초기 스타트업 DB
```

**제가 못 하는 이유**: 이 뷰들이 우리 integration 에 공유가 안 돼 있어 접근 자체가 404 입니다.

---

# 새로 만든 뷰 — 보시고 마음에 안 들면 말씀해주세요

기존 뷰는 하나도 안 건드렸습니다. **새 탭이 하나씩 늘었을 뿐**입니다.

| DB | 뷰 이름 | 무엇이 달라지나 |
|---|---|---|
| 그물망 링크드인 소싱 | `오늘 훑기` | **41칸 → 6칸.** 최신순 → Tier순 |
| 그물망 앱스토어 소싱 | `오늘 훑기` | **21칸 → 6칸.** 최신순 → 판정순 |
| 극초기 스타트업 DB | `상태별` | Status 별 보드. 드랍완료 476건이 한 칸으로 접힙니다 |

**필터는 일부러 안 걸었습니다.** 필터를 걸면 사람이 보는 것과 코드가 읽는 것이 달라져서,
"노션엔 없던데" 가 나옵니다. 정렬과 칸 숨김만 했습니다 — **아무것도 안 사라집니다.**

극초기는 필터 대신 **보드로 묶었습니다.** 1,303행 중 69%가 이미 결론난 것(드랍완료 476 ·
미팅X 427)이라, 그것들이 접히면 진행 중인 것만 눈에 들어옵니다.

# 1·2번이 끝나면 제가 할 것

```
PROMOTE_ENABLED = True 로 바꾼다        ✅ 를 받은 사람이 극초기로 올라가기 시작
오늘 찌꺼기 정리                        극초기 5행 아카이브 · SampleProduct/Example Person B 합치기
```

승격은 이렇게 동작합니다:

```
✅ 를 받으면
   회사명    claude 가 헤드라인에서 찾는다. 못 찾으면 "이름 (스텔스)"
   링크      Homepage 우선, 없으면 링크드인 URL
   대조      이름 정규화 + Homepage 두 가지로 기존 행과 대조. 있으면 안 만든다
   Status   1. 미팅여부 결정전
```

회사명을 제대로 찾는 것이 **중복 문제도 같이 풉니다.** `SampleProduct`(회사)와 `Example Person B`(사람)이
두 행으로 갈린 게 그 문제였으니까요.
