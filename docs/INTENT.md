# 의도 — 무엇을 만들기로 했나

> **인턴 업무를 어떤 실패도 조용히 지나가지 못하는 최소 구조로 자동화한다.**

이 문서는 장식이 아니라 **검사 기준**이다. 코드를 한 덩이 지을 때마다 여기 와서
하나씩 대조한다. 못 지킨 게 있으면 지켰다고 적지 말고 **못 지켰다고 적는다.**

## B. 사람이 보는 것

기계로 못 세지만 매 단계 눈으로 확인한다.

| # | 의도 | 확인 방법 |
|---|---|---|
| B1 | **못 한 일을 숨기지 않는다** | 망을 끊고 돌려본다. "0건"이 아니라 "못 붙었다"가 나오는가 |
| B2 | **되돌릴 수 있는 건 안 묻는다** | 사람에게 묻는 지점을 센다. 늘었으면 왜 늘었나 |
| B3 | **사람이 이미 있는 곳으로 간다** | 새로 봐야 할 화면이 생겼나. 생겼으면 안 된다 |
| B4 | **스킬끼리 안 부른다** | 다른 스킬을 import 하거나 그 파일을 읽는 곳이 있나 |
| B5 | **하나 지워도 안 깨진다** | 스킬 폴더를 지워보고 다른 게 도는지 확인 |
| B6 | **claude 가 틀려도 "덜 함"이다** | 절차를 일부러 건너뛰고 돌려본다. 데이터가 망가지나 |
| B7 | **보고가 장부에서 나온다** | 착지를 막고 돌려본다. 보고가 0건이라고 하는가 |
| B8 | **방어 코드가 근거를 가리킨다** | 새 방어 코드마다 [0] 제약 중 무엇인지 적혀 있나 |
| B9 | **신호 없이 층을 안 만든다** | 이번에 만든 것 중 "아직 안 겪은 문제"를 막는 게 있나 |

### 자동화 차단 확인 · 승격 개시 (2026-08-19)

**🔴 "껐다"를 믿지 않고 시험해서 절반만 꺼진 걸 잡았다**

```
1차 시험   체크박스 켜기 → 90초 → Pick 27 그대로 ✅ · 극초기 1,303 → 1,304 🔴
           자동화가 **두 갈래**였다. 하나만 꺼져 있었다.
           생긴 행: 법인(서비스)="Irvan Smith" ← 사람 이름. 오염이 그대로 재현
```

시험 안 하고 넘어갔으면 `PROMOTE_ENABLED=True` 와 겹쳐 **오늘부터 이중 생성**이 났다.
