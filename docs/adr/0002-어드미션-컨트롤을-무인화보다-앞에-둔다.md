> 날짜: 2026-07-28 · 결정자: 박정현

## 맥락 — 결정 시점의 사실

### 지금 브레이크는 코드가 아니라 사람이다

그물망 소싱 1회에 ~$10.5 가 나간다. 크론은 꺼져 있고, 안 켠 이유는
*"돌리면 얼마 나가지?"* 라는 망설임이다. `net-sourcing/SKILL.md` 에 그대로 적혀 있다:

> **"결정 #6(수동 실행)이 지금까지 사실상 월 예산 가드였고, 크론은 그 사람을 없앤다."**

### 🔴 그리고 가드가 있다고 믿는 구간이 있었다

| | 값 |
|---|---|
| Apify 플랜(STARTER) 실제 한도 | **$29** |
| net-sourcing 이 믿던 상한 | **$45** |
| ai-consumer-pulse 의 월 상한 | **없음** (경고만) |
| 이번 달 실사용 | $20.07 |

`$29~$45` 는 **가드가 있다고 믿지만 실제로는 없는 구간**이었다.
기존 가드였다면 `$20.07 + $10.50 = $30.57 < $45` 로 통과시켰을 것이고,
Apify 가 $29 에서 끊어 **돈은 쓰고 결과는 반쪽**이 됐을 것이다.

그리고 계정을 공유하는데 한쪽만 절제했다 — **절제하는 쪽만 손해를 보는 구조**였다.

### 앱스토어 Δ는 8일 비어 있었다

`tools/board.py` 가 `sys.path` 에 프로젝트 루트를 안 넣어 07-20 부터 깨져 있었다.
로그엔 트레이스백이 찍혔지만 **아무도 안 봤다.** 애플은 과거 순위를 안 주므로 그 8일은 영구 손실이다.

## 결정

**① 예산 게이트를 무인화(W6)보다 앞에 만든다.**
**② 계층 A(상시 실행)를 만들고, 배치 기준은 비용이 아니라 신뢰 경계로 한다.**

### 왜 무인화보다 앞인가

암묵적 통제(사람의 망설임)를 명시적 통제(코드)로 **옮겨놓고 나서** 사람을 빼야 한다.
순서를 바꾸면 브레이크가 없는 상태로 자동 실행이 시작된다.

> 자동화는 사람을 실행에서 빼는데, **그 사람이 하던 비공식 안전장치까지 같이 빠진다.**
> (irony of automation — 항공·산업제어에서 오래된 문제)

### 왜 각자 관리가 아니라 단일 관문인가

공유 자원에서 각자가 국소적으로 합리적인 판단을 하면 전역적으로 악화된다.
절제는 개인에게 손해고 남용은 이득이라 **절제하는 쪽이 도태된다**(공유지의 비극).
해법은 각자를 똑똑하게 만드는 게 아니라 **결정 지점을 하나로 올리는 것**이다.

### 왜 낮은 쪽 천장인가

우리 설정이 플랫폼 한도보다 높으면 그 구간의 가드는 **한 번도 발동하지 않는다.**
발동하지 않는 가드는 없는 가드보다 나쁘다 — **있다고 믿게 만들기 때문이다.**

### 왜 배치 기준이 신뢰 경계인가

*"GitHub 이 공짜니까 다 옮기면 되지 않나"* 가 자연스러운 생각이지만,
결정 요인은 비용이 아니라 **비밀이 어디까지 나가느냐**다.

```
앱스토어   공개 데이터 · 인증 불필요  → 들고 갈 열쇠가 없다 → 외부 가능
메일·노션  회사 자격증명 필요        → 열쇠를 딸려 보내야 한다 → 내부에 남는다
```

이 선을 한 번 그으면 앞으로 *"이 잡을 어디서 돌릴까"* 를 매번 고민하지 않아도 된다.

## 대가 — 무엇을 잃었나

**① 실행 지점이 둘이 됐다.** 맥북 launchd 와 GitHub Actions 가 같은 시각에 같은 일을 한다.
관측·디버깅 지점이 둘이고, 어느 쪽 스냅샷이 정본인지 규칙이 필요해졌다(로컬 우선).
3일 관찰 후 launchd 쪽을 제거하면 해소된다.

**② 게이트가 실제 소비의 일부만 덮는다.** Claude 구독 소비는 계측 경로가 없다.
"우리는 월 $X 쓴다"가 **부분적으로만 참**이다. W6에서 다시 봐야 한다.

**③ 알림 경로가 비대칭이다.** 로컬은 Slack 으로 알리지만 Actions 는 못 한다
(웹훅도 열쇠라 반출 금지). GitHub 기본 메일 + 로컬 밀림 감지 두 경로에 의존한다.

## 이 결정이 틀렸다면 어떻게 알 수 있나

### 🔴 결정적 신호

**게이트가 정상 실행을 막기 시작한다.** 임계값이 실제 소비 패턴과 안 맞는다는 뜻이다.
`--force-budget` 을 쓰는 횟수가 늘면 그게 신호다 — **우회가 잦으면 규칙이 틀린 것이다.**

**Actions 가 조용히 안 돈다.** 60일 비활성화·스케줄 누락·러너 차단.
로컬 밀림 감지가 이걸 잡아야 하는데, 맥북도 꺼져 있으면 둘 다 못 본다.

### ⚠️ 경고 신호

| 신호 | 뜻 |
|---|---|
| 로컬과 러너 스냅샷이 크게 어긋난다 | 촬영 시각 차이 이상의 원인 (지역·차단) |
| `data` 브랜치 커밋이 하루 걸렀다 | 스케줄 누락 또는 산출물 검증 실패 |
| 게이트 조회 실패가 잦다 | fail-open 이라 통과하는데, 그만큼 가드가 없는 실행이 는다 |

### 판정 시점

**W6(무인화)** 이 첫 시험이다. 사람 없이 도는 상태에서 예산이 지켜지는지,
그리고 Claude 구독 쿼터가 새 병목이 되는지가 그때 드러난다.
