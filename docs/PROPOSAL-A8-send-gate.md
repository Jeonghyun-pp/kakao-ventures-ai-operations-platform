# 제안 — A8 재설계: "발송 경로 0건" → "발송은 한 문으로만" (2026-09-21, 미구현)

## 지금의 A8

`check_intent.py a8_no_send()` — 금지 엔드포인트 5종(`/send`·`/trash`·`/batchDelete`·`/import`·`/insert`),
SDK send 체인, `smtplib` import 가 **리포 어디에도 없음**을 정적으로 확인한다. 아카이브(`/modify`)와
초안 생성(`POST /drafts`)만 허용한다. 3주 운영에서 바깥으로 잘못 나간 메일이 0건인 근거가 이것이다.

## 왜 바꿔야 하나

재구축의 목표는 담당자 없이 정형 회신이 **실제로 발송**되는 것이다. 발송 코드를 넣는 순간 A8 은 실패한다.
선택지는 셋이고, 앞의 둘은 안 된다.

| 선택지 | 문제 |
|---|---|
| A8 을 끈다 | 가장 비싼 실수(잘못된 메일이 회사 이름으로 나감)를 막던 유일한 구조적 장치가 사라진다 |
| 발송 파일을 예외 명단에 넣는다 | "그 파일 안에서는 뭐든 된다"가 된다. 이 리포가 피해 온 카테고리 면제다 |
| **문을 하나로 좁히고, 그 문의 조건을 검사한다** | 아래 |

## 새 불변식 (안)

**A8a — 발송 엔드포인트는 한 파일에만 있다.**
`kv_transport/gmail_send.py`(신규) 밖에 금지 엔드포인트 문자열·SDK send·smtplib 가 0건. 기존 `gmail.py` 에도 없다 —
읽기·아카이브·초안 통로와 발송 통로를 파일로 가른다. 나머지 네 엔드포인트(`/trash` 등)는 지금처럼 전역 0건.

**A8b — 그 파일의 공개 함수는 하나이고, 허가증 없이는 못 부른다.**
`send(permit, …)` 하나. `permit` 은 `SendPermit` 객체이고 **생성자가 모듈 밖에서 호출되면 실패**한다(정적으로 호출 위치 확인).
허가증을 만들 수 있는 곳은 발송 직전 검사 함수 하나뿐이다.

**A8c — 허가증은 아래를 전부 통과해야 나온다.** (런타임 · 테스트로 고정)
```
갈래 설정이 '자동' 또는 '결정 있음'      policies 에서 읽는다. 코드 상수로 두지 않는다
문안이 승인된 템플릿에서 나왔다          자유 생성 문안은 허가증을 못 받는다(이번 범위)
수신자가 그 업무의 연결 자료에서 나왔다   본문에서 새로 뽑은 주소가 아니다
실행 소유권이 이 시스템이다              옛 시스템 소유 메일에는 안 쓴다
스레드가 결정 이후 움직이지 않았다        기존 thread_after 재사용
같은 (업무·결정 버전·행동) 이 실행된 적 없다
하루 실행 상한 안이다                   constraints.yaml
즉시 차단 스위치가 꺼져 있다
```

**A8d — 발송은 의도 기록 → 발송 → 보낸편지함 확인 순서다.**
의도 기록 없이 `send` 가 불리면 실패. 결과 불명이면 재발송하지 않고 대조 절차로 넘긴다.

**A8e — 억제는 실패가 아니지만 성공도 아니다.**
모의 실행·차단 스위치로 막혔을 때 "발송됨"으로 기록하지 않는다(`slack.py` 의 `KV_NO_SEND` 교훈과 같다).

## 검사가 실제로 무는지

`tools/mutation_test.py` 에 변이를 추가한다 — 각각 검사가 실패해야 인정한다.
```
다른 파일에 /send 문자열을 넣는다                    → A8a
gmail_send 밖에서 SendPermit 을 직접 만든다           → A8b
갈래 설정이 '꺼짐'인데 허가증 발급을 시도한다          → A8c (테스트)
의도 기록 없이 send 를 부른다                        → A8d (테스트)
```

## 순서

1. 이 문서 승인
2. `gmail_send.py` 를 **모의 실행만 되는 상태로** 먼저 넣고 A8a~e 와 변이 테스트를 통과시킨다
3. 관찰 모드에서 "허가증이 나왔을 건"을 기록한다 — 주간 판정 목록의 재료가 된다
4. 갈래별로 실제 발송을 켠다(계획 §9)

그 전까지 현행 A8 은 **그대로 둔다.** 새 검사가 통과하기 전에 옛 검사를 지우지 않는다.
