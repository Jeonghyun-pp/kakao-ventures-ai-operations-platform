# 앱스토어 소싱

## 하루

```
09:10  collect   25장르 × 4차트 → 처음 보는 앱 → 6개월 이내 → 국적 필터 → 한국 앱만 노션 착지

🔴 왜 9시 이후인가: 맥이 자다 깨면 launchd 가 밀린 작업을 **즉시** 발화하는데, 그때가
   DNS 가 아직 안 올라온 순간이다. 옛 시스템이 그걸로 76요청을 전멸시킨 적이 있다.
   이미 깨어 있는 시각에 돌리면 그 위험이 없다.
```

## 명령

```bash
cd ~/kv
./.venv/bin/python -m skills.appstore.run collect [--dry-run] [--limit N] [--genres N]
./.venv/bin/python -m skills.appstore.run status
```

`KV_NO_SEND=1` 을 붙이면 슬랙이 안 나간다. **억제는 실패가 아니라 억제**로 기록된다.

## 구성

```
run.py       진입점 셋 + 스킬 고유 로직 (후보 추출 · 프로퍼티 매핑)
itunes.py    통로 — 애플에 닿는 유일한 경로
notion.py    통로 — 노션에 닿는 유일한 경로
claude.py    통로 — 판단을 부르는 유일한 경로
slack.py     통로 — 알림이 나가는 유일한 경로
ledger.py    장부 — 멱등·재개·보고가 전부 여기서 나온다
criteria.md  뭘 고를지 (첫 주 돌려보며 채운다)
```

통로 4개와 장부는 **링크드인 스킬을 만들 때** 실물 둘을 놓고 겹치는 데까지 밖으로 뺀다.
미리 빼지 않는다 — 옛 시스템은 감으로 선을 그었고, 그래서 두 겹이 됐다.

## 지키는 규율

```
착지 먼저, 장부 나중     순서가 반대면 착지 실패한 것이 "처리됨"으로 남아 영영 안 잡힌다
빈 배열은 측정된 0       카지노 유료 차트는 애플의 정답이다. 결손이 아니다
미상은 0건이 아니다      망이 죽으면 unknown 이고 종료코드가 0이 아니다
쓴 것은 되읽는다        200 은 저장을 뜻하지 않는다
옵션은 라이브에서       코드 상수를 믿으면 사람이 추가한 옵션을 되돌린다
보고는 장부에서         claude 기억이 아니라 줄 수를 센다
```

## 알아둘 것

**한국팀 여부를 정규식으로 맞히려 하지 마라.** 옛 시스템이 실측했다 — 넓게 잡으면
424개 중 225개가 한국으로 찍히는데 절반이 오탐이고, 좁게 잡으면 실제 123개 중 100개를
놓친다. 그래서 개발사 도메인을 그대로 보여주고 사람이 0.5초에 판단한다.

**`genre=36` 단독으로 쓰지 마라.** 신규진입 29건 중 24건이 홈플러스·배민·라인의
시즌성 재진입이었다. 25개 카테고리로 쪼개야 극초기 앱이 보인다.

**최신출시 피드는 genre 를 무시한다.** 장르별로 부르면 같은 응답을 25번 받는다.
코드가 그 호출을 거부한다.
