# 앱스토어 — 무엇을 고를 것인가

> 🔴 **이 문서는 아직 골격이다.** 첫 주 돌려보면서 채운다.
> 정현님이 노션에서 빼신 것들이 곧 여기 들어갈 내용이다.

## 우리가 찾는 것

카카오벤처스가 **극초기에 만나볼 값어치가 있는 팀**이 만든 앱.
판단은 심사역이 한다. 여기서 하는 일은 **오늘 후보 중 사람이 직접 볼 것 몇 개를 고르는 것**이다.

절대 기준으로 Pass/Drop 을 가르는 게 아니다 — 그건 옛 시스템이 해봤고,
통과율이 목표의 9배로 샜다. 우리는 **오늘 것 중 상위 몇 개**를 고른다.

## 볼 수 있는 것 / 볼 수 없는 것

받아오는 정보는 이게 전부다.

```
앱 이름 · 설명 · 부제
개발사명 · 개발사 도메인
출시일 · 차트와 순위 · 장르
평점 · 리뷰 수
```

**팀 구성은 알 수 없다.** 창업자가 몇 명인지, 뭘 하던 사람인지 여기엔 없다.
그러니 "좋은 팀"을 판정하려 하지 말고, **볼 값어치가 있는지**만 본다.

## 신호 (초안 — 첫 주에 검증한다)

**올리는 쪽**

- 개발사명이 **사람 이름이거나 작은 법인**으로 보인다 — 대기업 부서 산출물이 아니다
- 개발사 도메인이 **한국**이다 (`.kr`, 한국어 사이트). 도메인은 그대로 노출하고 사람이 0.5초에 판단한다
- **출시 직후인데 차트에 들었다** — 초기 트랙션 신호
- 리뷰 수가 적은데 평점이 높다 — 초기인데 반응이 좋다
- 설명이 **뾰족하다** — 누구의 어떤 문제를 푸는지가 구체적이다

**내리는 쪽**

- 대기업·기존 브랜드의 앱 (금융사·통신사·유통·게임 대형 퍼블리셔)
- 시즌성 재진입 (명절·이벤트로 잠깐 오르는 것)
- 도박·성인·대출·다이어트 보조제류
- 설명이 광고문구뿐이고 뭘 하는지 안 보인다
- 해외 대형 앱의 한국판

## 하지 말 것

**한국팀 여부를 정규식이나 키워드로 맞히려 하지 마라.**
옛 시스템이 실측했다 — 넓게 잡으면 424개 중 225개가 한국으로 찍히는데 절반이 오탐이고,
좁게 잡으면 실제 한국팀 123개 중 100개를 놓친다. **어느 임계를 잡아도 절반이 틀린다.**
그래서 판단을 포기하고 개발사 도메인을 그대로 보여주기로 했다. 되돌리지 마라.

## 몇 개를 고르나

기본 2개. 후보가 그보다 적으면 있는 만큼만 — **억지로 채우려고 기준을 낮추지 않는다.**
