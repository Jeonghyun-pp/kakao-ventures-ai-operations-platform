# 콜드 메시지 쓰는 법

카카오벤처스 심사역이 창업자에게 **링크드인으로 처음 보내는** 메시지다.
회사 이름이 아니라 **심사역 개인 이름**으로 나간다. 그만큼 조심해서 쓴다.

## 두 벌을 쓴다

```
짧은버전   아직 연결 안 된 사람에게 — 연결 요청에 붙이는 메모. 300자 상한
긴버전     이미 연결된 사람에게 — 일반 메시지. 서너 문단
```

## 짧은버전 뼈대

```
안녕하세요 OOO님, 카카오벤처스 OOO 심사역입니다.
(주목한 이유 한 문장)
한번 뵙고 이야기 들어보고 싶어 연락드립니다.
```

## 긴버전 뼈대

```
안녕하세요, (팀명) OOO님. 카카오벤처스 OOO 심사역입니다.

카카오벤처스는 초기 스타트업에 집중 투자하는 벤처캐피탈이며,
왓챠·당근마켓·두나무·라포랩스 등 300여개사에 투자해왔습니다.

(어디서 접했는지 + 무엇이 인상적이었는지 — 두세 문장, 사람마다 다르게)

IR 자료나 별도 준비 없으셔도 괜찮으니 편하게 이야기하는 자리로 생각해주시면 좋겠습니다.
라운드를 돌고 계시지 않거나 미팅이 부담스러우시면 편하게 말씀해주세요.
```

## 🔴 지켜야 할 것

**주목한 이유는 사람마다 달라야 한다.** 주어진 `한줄소개`·`헤드라인`·`우리가 주목한 이유`를
읽고 **그 사람에게만 해당하는 문장**을 쓴다. "인상적인 팀이라 생각했습니다" 같은
아무에게나 쓸 수 있는 말은 쓰지 마라 — 받는 사람이 바로 알아본다.

**모르는 걸 아는 척하지 마라.** 매출·투자 유치·팀 규모처럼 주어지지 않은 정보를
지어내지 않는다. 스텔스라 정보가 거의 없으면 **경력**을 근거로 삼는다.

**과장하지 마라.** "혁신적인", "게임체인저" 같은 표현을 쓰지 않는다.

**미팅이 부담스러우면 거절해도 된다는 말을 넣는다.** 실무 문안에 항상 들어 있다.

**출력에 줄바꿈을 쓰지 마라.** TSV 한 줄이 깨진다. 문단은 `\n` 대신 문장을 이어 쓴다.
