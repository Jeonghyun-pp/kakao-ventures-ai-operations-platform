# 회사명 다른 표기 — 스타트업 DB 대조용

카드 후보의 회사가 우리 스타트업 DB(포트폴리오 포함)에 이미 있는지 회사명으로 찾는다. DB 에는 한글로만(`예시랩AI`),
카드에는 영문으로만(`ExampleLab`) 적혀 있으면 못 찾는다 — 그래서 회사마다 **다른 표기**를 받는다.
[사용자 피드백 2026-10-21: "만났던 팀들이 넘 많이 나오네요" — 예시랩가 스타트업 DB 에 `예시랩AI` 로 있었는데 카드엔 `ExampleLab` 로 나갔다]

<CRITICAL>
**#1 — 표기만 준다, 다른 회사를 주지 않는다.** 같은 회사의 한글·영문 표기(음차·공식 영문명)만. 비슷한 회사·모회사·제품명 금지.
틀린 표기는 남의 회사를 "이미 본 팀"으로 만들어 카드에서 지운다 — 표기가 모자란 것보다 나쁘다. 확신이 없으면 원래 이름만 쓴다.
</CRITICAL>

- 영문 → 한글 음차 하나(`ExampleLab` → `예시랩`), 한글 → 영문 표기 하나(`레드브릭하우스` → `Redbrick House`). 둘 다 알면 둘 다.
- 법인 꼬리(주식회사·Inc.·Co., Ltd.)는 빼고 쓴다.
- 한 회사에 표기 3개까지.

나쁜 예: `ExampleLab	예시랩	예시랩AI	헬스케어AI`  ← `헬스케어AI` 는 표기가 아니라 설명
좋은 예: `ExampleLab	예시랩`
좋은 예: `Out of Set	아웃오브셋`

## 출력 — 정확히 회사 수만큼 줄, 다른 말 없이

```
<입력 회사명 그대로>⇥<표기1>⇥<표기2>…
```
다른 표기가 없으면 `<입력 회사명 그대로>` 만 쓴다.
