# 카드 문안 쓰는 법

심사역이 슬랙에서 **5초 안에 읽고 "만날까 말까"를 판단**할 수 있게 쓴다.

## 두 가지를 만든다

```
회사명    법인·서비스 이름. 못 찾으면 정확히 `(미상)`
두 문장   무엇을 만드는지 · 왜 지금인지
```

## 🔴 회사명 — 칸을 믿지 마라

주어지는 `회사칸` 은 링크드인이 준 슬러그라 **믿을 수 없다.** 실측했다:

```
stealth-startup-community   회사가 아니라 플레이스홀더
divitas-networks            헤드라인은 Stealth 인데 이 값이 있다 → 옛 직장
```

**헤드라인·소개글을 읽고 판단한다.**
```
"Building AI Focus Agent @SampleProduct"        → SampleProduct
"Co-Founder & CTO at CarbonSix, MIT PhD"  → CarbonSix
"Stealth Mode | Building an efficient..."  → (미상)
```

🔴 **스텔스면 억지로 채우지 마라.** `(미상)` 이 정직한 답이고, 그게 이 채널의 정상 상태다.
없는 회사명을 지어내면 나중에 중복 대조가 통째로 어긋난다.

## 두 문장

**첫 문장 — 무엇을 만드나**
```
좋음   화면을 저장하지 않고 집중도를 재는 macOS 시간 추적입니다.
나쁨   AI 기반 혁신적인 생산성 솔루션입니다.        ← 아무에게나 해당한다
```

**둘째 문장 — 왜 지금 볼 만한가**
```
좋음   ML 가속기와 프로세서 설계를 해온 사람이 이달 서빙 인프라로 창업했습니다.
좋음   essentory 를 엑싯한 창업자가 지난달 다시 시작했습니다.
좋음   고려대 AI 박사과정이 3개월 전 공동창업했습니다.
```

## 🔴 모르면 모른다고 쓴다

정보가 없는 것이 이 채널의 정상이다. **비워두지 말고 없다고 적는다.**
```
무엇을 만드는지는 아직 안 밝혔습니다.
이번에 무엇을 만드는지는 프로필에 없습니다.
본업인지 부업인지는 프로필만으로 안 갈립니다.
```

매출·투자 유치·팀 규모처럼 **주어지지 않은 것을 지어내지 마라.** 스텔스라 정보가 없으면
**경력**을 근거로 삼는다.

## 지킬 것

```
과장 금지        "혁신적인" · "게임체인저" · "차세대" 를 쓰지 않는다
출력에 줄바꿈 금지  TSV 한 줄이 깨진다. 두 문장을 이어 쓴다
두 문장까지       세 문장 넘어가면 5초 안에 못 읽는다
```
