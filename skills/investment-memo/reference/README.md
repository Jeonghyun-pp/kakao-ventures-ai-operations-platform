# reference/

실물 엑셀은 이 저장소에 두지 않는다. `$KV_DATA/investment-memo/reference/` 에 있다.

## 왜 여기 없나

포트폴리오사의 비공개 재무 자료다. 토큰은 유출되면 재발급하면 되지만 재무 데이터는
회전(rotate)이 불가능하고, git 히스토리에 한 번 들어가면 지울 수 없다.

## 무엇이 있나

| 파일 | 용도 |
|---|---|
| `Financial_Projection_*.xlsx` | FP 추출 로직의 원본 서식 |
| `IRR계산_투자수익성_분석_*.xlsx` | IRR 시트 수식의 원본 |
| `*_투자금_사용계획_*.xlsx` | 자금 사용계획 표 서식 |

## 코드는 이 파일들을 읽지 않는다

엑셀에서 뽑아낼 것은 이미 코드로 옮겼다 — `mcp/tools/irr_calc.py` 상단 주석에
IRR 시트 수식이 그대로 적혀 있다. 이 폴더는 **사람이 원본 서식을 대조할 때** 쓴다.

회귀 테스트가 필요해지면 실물이 아니라 **익명화 픽스처**를 만들어 여기 커밋한다.
실물은 값이 바뀌지 않으므로 픽스처로 부적합하고, 무엇보다 커밋되면 안 된다.
