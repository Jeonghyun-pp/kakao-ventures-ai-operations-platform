회수 방안(Exit Strategy)과 투자 수익성(Valuation / IRR)을 묶어 정리한다.
투자위원회가 "이 투자가 어떤 방식으로 회수되고, 목표 IRR이 충분한가"를
판단할 수 있어야 한다.

## 목적
투자위원회가 회수 방식과 목표 수익률을 판단할 수 있도록, 회수 방안 선택
사유와 기대 수익성을 논증한다.

## 정보 소스 리스트
1. **Investment theme (중심)** — Valuation 로직과 회수 시나리오의 핵심은 investment theme(심사역 코멘트)을 중심으로 작성함
2. **IR 덱 / 사업계획서 (PDF, 보완)** — investment theme 관련 내용이나 추가로 보완할 부분은 IR 덱을 참고하여 작성함
3. **Financial Projection** — Exit 연도 매출(ARR/GMV/Direct Margin/매출액)과 영업이익, 흑자전환 시점 (회수 방안 결정과 IRR 계산의 기준)
4. **웹 검색 (피어그룹·시가총액 필수 활용)** — 피어 기업의 시가총액, 매출, PSR/PER을 웹 검색으로 확인함 (작성 시점 환율·기준일 명시)
5. **투자 조건** — Pre 밸류, 투자금액, 투자 연도 (지분율·투자기간 계산)
6. **미팅 노트** — 잠재 인수자, 회수 관련 대표 코멘트

## 회수 방안 결정 (Exit Strategy)
- **기본은 M&A**로 작성함 (한국 VC 시장 회수의 대다수). **IPO인 경우는 사용자가 사전에 알려주며, 그 경우 IPO 기준으로 작성함**
- M&A 선택 기준 (아래 중 하나라도 해당): ① 펀딩 기간 이내 IPO가 어려움(매출 상승 느림) ② IPO보다 M&A 가능성이 월등 ③ 기술기업
- IPO 선택 시: FP 매출/영업이익이 IPO 기준 충족 + 펀드 만기일 이전 IPO 가능 — 구체 수치와 상장 시장(KOSDAQ 일반/기술특례/KOSPI), 펀드 만기 vs 예상 IPO 시점 비교를 명시함

## 작성 지침

### 구조
공통스타일의 볼드 헤드라인 + 불릿 양식을 따르며, 아래 순서로 작성함.

1. **회수 방안 (M&A 또는 IPO)** — 회수 방안 선택 사유(위 3기준 중 어느 것)를 서술함
2. **M&A 매력 포인트 (일반론)** — 이 회사가 M&A 대상으로서 **어떤 점이 매력적인지**를 먼저 서술하고, 그래서 **일반적으로 어떤 카테고리의 기업**(예: 엔터사, 플랫폼 기업, 유통사 등)이 관심을 가질지를 제시함
3. **M&A 후보 테이블** (M&A인 경우 필수) — 구체적인 잠재 인수자를 표로 제시함

```
| 회사 | 기대치 | 당위성 |
|------|--------|--------|
| (구체 법인명) | 상/중상/중 (또는 공격적/평균/보수적) | ① 어떤 기업인지 간단 소개 ② 왜 인수할 것 같은지 논리(이전 유사 인수 경험·연도·금액 등) ③ 인수 시 시너지(인수 목적). 인수 이력 등 사실 근거에는 출처 링크 첨부 |
```
   - **전략적 인수자(Strategic) 2~4개 + 재무적 인수자(Financial, Growth PE) 1개 이상**을 반드시 포함함
   - 각 후보는 반드시 **① 간단 소개 ② 인수 논리(이전 유사 인수 경험 등) ③ 인수 시 시너지(인수 목적)** 를 모두 포함함
   - "관심 있을 것" / "시너지 가능" 같은 막연한 서술 금지 — "2023년 OO를 OO억에 인수 + 현재 OO 확장 중 + 피투자사의 OO 자산 즉시 활용 가능" 식 구체 근거로 작성하고, **인수 이력 등 사실에는 출처 링크를 첨부**함
4. **투자 수익성 분석 — Peer Group** — **investment theme을 기준으로, 비즈니스 모델과 사업이 최대한 유사한 피어 기업을 선정**하고, **왜 그 피어를 선정했는지 사유를 반드시 명시함**. 각 피어의 매출·시가총액·PSR을 제시하며, **PSR 산출에 참고한 웹 출처 링크를 반드시 첨부**하여 사용자가 직접 확인·검증할 수 있게 함
5. **적정 P/S 및 PSR 시나리오** — 피어 평균 PSR을 기준으로 적정 P/S를 산출하고(보수적 평균 또는 라운딩), 보수/평균/공격 3시나리오를 제시함 (디폴트 ±30%)
6. **IRR 분석** — Exit 매출 × PSR × 지분율로 회수금액·Multiple·연환산 IRR을 보수/평균/공격으로 제시함 (수치 테이블은 IRR 계산 Excel에서 산출하여 삽입)

### 핵심 계산 (참고)
```
Post-money = Pre + 투자금액 ;  지분율 = 투자금액 / Post-money ;  투자기간 = Exit연도 - 투자연도
시가총액 = Exit매출 × PSR ;  회수금액 = 시가총액 × 지분율 ;  Multiple = 회수금액 / 투자금액 ;  IRR = Multiple^(1/투자기간) - 1
적정 P/S: 보수 = ×0.7, 평균 = ×1.0, 공격 = ×1.3 (디폴트 ±30%, 조정 시 사유 명시)
```

## 작성 시 주의사항
- **피어그룹은 investment theme을 기준으로, 표면적 카테고리(이커머스, B2B SaaS)가 아니라 비즈니스 모델과 사업이 최대한 유사한 기업으로 선정함** (예: "양국 통관·다통화 직구 대행", "Vertical SaaS 산업 특화 ARPU Upsell"). **선정 이유를 반드시 본문에 명시함**
- 피어는 상장 기업 우선, 2~3개 선정, 매출 규모는 피투자사 Exit 매출의 5~30배 권장
- **PSR 산출에 참고한 웹 출처(피어 시가총액·매출의 근거)는 반드시 링크로 첨부**하여 사용자가 직접 확인·검증할 수 있게 함 (예: `(출처: https://...)`)
- **M&A 후보의 인수 이력 등 사실 근거에도 출처 링크를 첨부**함
- PSR/PER은 **시가총액** 사용, EV/EBITDA만 기업가치(EV) 사용 (시가총액 ≠ 기업가치)
- 환율 환산 시 작성 시점 환율 명시 (JPY ≈ ×9.5, USD ≈ ×1,400은 가이드값)
- FP의 매출 정의(ARR/GMV/Direct Margin)와 IRR 계산의 매출 정의가 정확히 일치해야 함
- IRR 수치 테이블은 IRR 계산 Excel에서 산출함 (수식 무결성 유지, 조정 케이스는 Word 출력만 라운드 숫자 + 사유 명시)

## 정보 부족 시 처리 방법
- Financial Projection이 없어 Exit 매출을 알 수 없으면 "(IRR 산출 불가 — Financial Projection 필요)"로 표기함
- 피어 데이터를 웹 검색으로도 확보하지 못하면 "(피어 데이터 미확보 — 추가 조사 필요)"로 표기함
