# 자율성 — 측정 · 승격 · 발송 구현 계약

최종 목표(2026-07-17 사용자 결정): **L2(채용·사칭·미팅)만 사람에게 남기고 전면 무인.**
경로는 감이 아니라 측정: 초안이 무수정으로 발송되는 카테고리만 단계적으로 승격한다.

## 측정 (P5 — 이미 가동)

- apply가 초안을 만들면 `data/sent_watch.jsonl`에 등록된다.
- metrics 단계가 Gmail Sent를 읽어 초안 원문과 대조: 정규화 후 포함 or 유사도 ≥0.98
  → 무수정. 30일 내 미발송이면 표본 제외(expired).
- 결과는 `data/metrics.jsonl`, 카테고리별 요약이 매 다이제스트에 실린다.

## 승격 절차 (P6 진입 조건)

| 조건 | 값 | 이유 |
|------|-----|------|
| 무수정 발송률 | ≥ 95% | 20건 중 1건 수정 미만 |
| 측정 기간 | 최근 21일 | 일시적 호조 배제 |
| 표본 수 | n ≥ 5 | n<5는 수치가 좋아도 우연 |
| 사람 판단 | 다이제스트 확인 습관이 자리 잡았는가 | veto가 "아무도 안 봄"이면 무의미 |

통과 시: config `autonomy.auto_send_categories`에 카테고리 추가. 예상 1차 후보:
`WEBFLOW`(구글폼 안내), `INBOUND_KO`(폼 안내) — 문구 고정·개인화 0.

## 발송 구현 계약 (P6에서 코드를 붙일 때 — 이 순서로 강제)

발송 함수는 다음 검사를 **이 순서로** 통과한 건만 보낸다. 하나라도 걸리면 초안 유지:

1. `category in never_auto_send` → **거부** (HARD-GATE #2. 첫 줄에서 검사)
2. `not send_enabled` → 거부
3. `category not in auto_send_categories` → 거부 (opt-in)
4. 오늘 발송 수 ≥ `daily_send_cap` → 거부 + 다이제스트 ⚠️ (서킷브레이커)
5. 이번 실행 UNKNOWN 비율 > `unknown_alert_ratio` → 전량 거부 (분류기 이상 신호)
6. veto window: 초안 생성 시각 + `veto_window_hours` 경과 전 → 대기.
   슬랙 통지에 명시된 취소 방법(초안 삭제 or 취소 라벨)이 감지되면 발송 취소.

발송 이상 징후 폴백 — 순서대로:
  1순위: 해당 건만 초안 폴백 / 2순위: 이번 실행 전체 초안 폴백 /
  3순위: `send_enabled: false` 강하 + ⚠️ 보고 / **금지: 이상 상태에서 발송 강행**

## 영구 제외 (never_auto_send)

| 카테고리 | 이유 |
|---|---|
| `PARTNERSHIP_DECLINE` | 가이드라인: 슬랙 패스 확인 "후" 발송. 순서를 코드가 보장 못 함 |
| `TRUSTED_REF` | 오판 시 구글폼을 건너뛴 특혜가 나감 |
| `RECRUIT` | 채용 진행 상태는 시점 의존 — 코드가 알 수 없음 |
| `IMPERSONATION` | 사칭 사안 — PR팀 소관, 자동 회신 절대 금지 |
